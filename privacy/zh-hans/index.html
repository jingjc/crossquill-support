1. 我们不收集的信息

  • 本应用不要求注册账户，也没有开发者账户系统。
  • 本应用不包含广告、广告追踪、第三方分析统计或崩溃上报 SDK，不使用广告标识符，不进行跨应用或跨网站追踪。
  • 您的聊天内容、附件、系统提示词、API 密钥和使用量记录不会发送给我们。
  • 应用会在设备的系统日志中记录少量诊断事件（如同步、保存、密钥访问的事件名、数量和错误类别），不包含正文、标题、密钥、路径或标识符，也不会被上传给我们。

2. 保存在您设备上的信息

信息用途保护方式
聊天记录（问题、回答、思考过程、系统提示词、来源链接、用量回执）、多模型分析记录在本机查看历史、继续对话加密保存在本机数据库中（AES-256-GCM，每条记录通过 HKDF-SHA256 派生独立密钥）。
各服务商的 API 密钥（含 OpenRouter 余额查询用的管理密钥）向对应服务商认证请求作为独立加密记录保存在同一本机数据库，不写入普通设置或明文文件，不参与同步。
附件原件与图片缩略预览编辑或重新生成时恢复附件、在历史中显示加密保存在本机；附件原件不进入同步。
显示与使用偏好（如“发送前确认”开关、字体）保持您的设置保存在系统的应用偏好设置中（未加密）。
向各服务商发送内容的同意记录（服务名称、所同意的告知版本、同意时间；Kimi 另记所同意的站点）判断是否已取得您对该服务商的同意只保存在本设备的应用偏好设置中（未加密），不含聊天内容或密钥，不参与同步；可在设置中逐项撤回。

数据库主密钥：

  • Mac： 随机生成的 256 位主密钥由 macOS 系统钥匙串保管。该钥匙串条目不参与 iCloud 钥匙串同步，读取时不弹出认证框；钥匙串不可用时应用停止打开数据，不会降级为明文，也不会改用新密钥或重建已有数据库。Mac 版不设应用密码，日常访问依赖您当前的 macOS 登录会话。
  • iPhone： 主密钥由您设置的 6 位锁定码保护（PBKDF2-HMAC-SHA256 派生的密钥加密封装）。您可以选择启用面容 ID／触控 ID：此时主密钥另存于仅限本设备、受当前生物识别保护的系统钥匙串项中，不随 iCloud 或备份迁移。您还可以预先生成恢复码，用于忘记锁定码时重新设置。若既没有预先启用的恢复码、生物识别也不可用，我们无法帮您恢复加密数据。

3. 发送给您选择的模型服务商的信息

接收方： 您在应用中选择并已保存密钥的服务商。本版本提供的服务：OpenRouter、DeepSeek、Kimi、OpenAI、Anthropic。您的版本实际提供哪些服务，以应用内“添加服务”列表为准。

  • Kimi 按站点区分接收方： Kimi 开放平台有国际站和中国站两个站点，账户与密钥互不通用。应用根据您的密钥识别其所属站点（见第 4 节），之后只与该站点通信。两个站点是不同的接收方，适用各自的隐私政策：国际站为 Kimi 开放平台国际站（Moonshot AI，接口地址 api.moonshot.ai，隐私政策 https://platform.kimi.ai/docs/agreement/userprivacy ）；中国站为 Kimi 开放平台中国站（月之暗面 Moonshot AI，接口地址 api.moonshot.cn，隐私政策 https://platform.kimi.com/docs/agreement/userprivacy ）。

发送时机：

  • 首次外发许可：每个接收方服务第一次收到您的内容之前，应用会单独说明接收方、将发送的数据类别、该服务商的隐私政策链接以及费用由其收取，并请您明确同意；未同意时不发送您的内容，也不为发送内容读取密钥（Kimi 站点识别除外：尚未同意当前版本的 Kimi 告知时，为发送内容而识别前另行说明并确认；识别只发送密钥，见第 4 节）。Kimi 按站点分别征求同意：对一个站点的同意不覆盖另一个站点，换用另一站点的密钥时会重新询问。同意只记录在本设备，可在设置中逐项撤回，撤回后下次发送前重新询问；告知内容更新后也会重新询问。该同意与下面的“发送前确认”相互独立，关闭“发送前确认”不会跳过它。只发送密钥的请求（读取模型目录、查询余额、识别 Kimi 站点）不需要此同意。
  • “发送前确认”默认开启。开启时，只有在您核对接收方、模型、上下文、附件和联网设置并点击确认后，应用才从本机解密所选服务商的密钥并连接该服务商（Kimi 站点识别除外，见第 4 节）。
  • 您可以在设置中关闭“发送前确认”。关闭后，点击发送并通过本机检查即会直接提交。
  • 一次确认可以覆盖一个请求批次，例如：多模型分析的多个阶段；Kimi 文档附件的上传与随后的删除请求。确认页会列出该批次的范围。
  • 应用不会自动重试失败的请求，不会静默更换模型或服务商，也不会添加隐藏提示词。

发送的内容： 您的问题原文、您填写的系统提示词、本对话中此前已完成的问答（以及该服务商要求回传的思考／工具上下文）、您选择的附件、联网或工具调用所需的数据，以及用于认证的 API 密钥。

  • 多模型分析： 一个模型的回答正文、来源链接会按您在确认页看到的范围转交给您选择的其他模型服务商；原始思考过程不跨模型转发。
  • 附件： 多数服务以请求内联方式发送附件。Kimi 的文档附件会先上传为您密钥所属站点上的 Kimi 远端文件，任务结束后应用请求删除；停止、失败或删除超时可能导致文件留在 Kimi，应用会列出未收到删除回执的文件供您处理。应用在本机记录每个远端文件的上传站点，删除请求只发往该站点；若您当前的密钥属于另一站点，这些记录会保留并提示，换回该站点的密钥后才能删除。
  • 联网搜索与官方工具： 开启后由所选服务商（或其路由的上游服务商）执行搜索或工具，可能另行计费。应用不会切换到第三方搜索服务。

服务商如何处理这些数据： 数据到达服务商后，由该服务商依据其自己的隐私政策、服务条款和您的账户设置处理（包括保留期限、是否用于改进模型、存储位置等），我们无法控制或删除服务商已收到的数据。请在使用前阅读各服务商的政策（链接见本页末）。以下几点与本应用的设置直接相关：

  • OpenRouter： OpenRouter 会把请求路由给上游模型服务商。本应用的 OpenRouter 对话默认使用“不保存对话”档：只选择标记为零数据保留（ZDR）、且不允许数据收集的运行渠道，失败时不改走其他渠道。您可以在当次运行中主动改为“允许保存，不允许收集”或“允许保存和收集”，界面会说明相应后果。您的 OpenRouter 账户隐私设置也会影响路由。
  • Anthropic： 部分型号按 Anthropic 的规定要求开启 30 天数据保留；应用在型号选择和发送确认中标注“要求 30 天数据保留”。
  • OpenAI： 本应用发出的 OpenAI 请求要求服务端不保存响应状态（store: false）；OpenAI 是否仍保留滥用监控日志等，以其政策为准。
  • Kimi： 数据由您密钥所属站点接收，按该站点的隐私政策处理（两个站点的政策不同，链接见上文“接收方”及第 16 节）。若您在 Kimi 官方工具中启用“云端记忆”，Kimi 可能保存工具调用中提交的内容；本应用没有该记忆的查看或删除入口，关闭开关也不会删除已保存内容。

4. 模型目录、余额查询与 Kimi 站点识别

  • 当您点击“保存并获取模型”、“重新获取模型”或刷新目录时，应用使用对应服务商的密钥向该服务商请求官方模型目录（OpenRouter 还会读取零数据保留端点和所选模型的运行渠道）。这些请求不包含聊天内容、系统提示词或附件，不触发模型生成。应用启动时不会自动读取目录。
  • 余额只在您主动点击查询时请求，不发送聊天内容。OpenRouter 余额需要单独的管理密钥，它与聊天密钥分开加密保存，仅用于余额查询。部分服务的余额无法在应用内查询。
  • Kimi 站点识别： 保存 Kimi 密钥时不联网。每次启动应用或更换密钥后，在第一次读取 Kimi 模型目录、查询 Kimi 余额、删除 Kimi 远端文件或向 Kimi 发送内容之前，应用会用该密钥先请求国际站（api.moonshot.ai）的模型目录；只有国际站以“未授权”（HTTP 401／403）拒绝时，才再请求中国站（api.moonshot.cn）的模型目录。这些请求只携带密钥，不包含聊天内容、系统提示词或附件，不触发模型生成。因此，属于中国站的密钥每次识别时都会先发送给国际站，识别未成功时不保留结果，您下次操作时会再次从国际站开始；两个站点都能看到您设备的网络地址。网络错误、超时、重定向或其他异常时识别立即停止，不再请求另一站点，也不会自动重试。识别结果只保存在内存中，不写入数据库、不同步；更换或删除密钥、重新启动应用后重新识别。识别完成后，该密钥的全部请求（聊天、附件上传与删除、模型目录、余额）只发往该站点，任何失败都不会改发另一站点。在您尚未同意当前版本的 Kimi 告知之前，为向 Kimi 发送内容而识别时，应用会先说明这一识别过程并请您确认后再进行；您主动发起的读取模型目录、查询余额和删除远端文件，应用在操作旁或删除确认框中说明，不另行询问。

5. 网页来源与链接

  • 显示含 DeepSeek 或 OpenRouter 结构化搜索来源的回答时（包括打开历史记录和同步到的对话），应用会自动向来源网站请求站点图标（先尝试网站根目录的 favicon，必要时读取网站首页并尝试其中声明的至多 3 个图标或标志图片）；打开来源列表时还会请求网页以读取标题。这些请求只访问 HTTPS 公网地址，不携带 Cookie 或账户凭据，使用通用的浏览器标识，不发送您的语言和地区偏好。标题请求访问来源网页本身的地址；图标请求不包含来源文章的路径和查询参数，但网站首页声明的图标可能位于其他路径或其他 HTTPS 主机，网站的重定向也可能把这些请求转到其他 HTTPS 主机。与访问任何网站一样，这些网站和主机可以看到您设备的网络地址。结果只缓存在内存中。
  • 对于从模型回答正文中提取的网址（例如 Kimi 工具结果），应用不会自动访问，并提示您在打开前核对完整地址。
  • 点击回答中的链接时，应用会先请您确认，再交由系统浏览器打开。

6. iCloud 同步（可选）

  • 同步默认不开启。只有您在同步设置中选择一个文件夹（通常位于 iCloud 云盘）并确认连接后，应用才会在该文件夹中读写同步文件。开启自动同步后，应用会自动读写该文件夹，包括 Mac 启动或 iPhone 解锁后、回到前台时、文件夹内容变化时，以及网络恢复后补传离线更新时；文件的上传和下载由系统或您选择的文件服务负责。
  • 同步文件不是本应用加密的： 同步副本是普通 JSON 文件，由您的 iCloud 账户及系统数据保护机制保护。未开启 iCloud 高级数据保护时，可以在“文件”App、访达或网页版 iCloud 中直接查看；本机锁定码不覆盖这些副本。若您选择非 iCloud 的位置，保护取决于该文件服务。本机数据库仍保持加密。
  • 同步内容包括已保存的聊天原文、思考过程、系统提示词、模型信息、用量、图片缩略预览（附件文件名替换为通用名称）、会话改名／置顶／删除，以及普通项目分类。多模型分析记录有一个默认关闭的共享开关，开启后其原文会随同步携带。
  • 以下内容不会进入同步：API 密钥、锁定码与恢复码、未发送的草稿、附件原文件、本地目录授权及绝对路径。
  • 原文中如果包含密钥或其他敏感文字，应用不会自动识别或脱敏，会随已开启的同步一起写出。

7. 设备备份与迁移

  • iPhone 的设备备份（iCloud 云备份或电脑备份）可能包含本应用的加密数据库；面容 ID 使用的钥匙串项仅限本设备，不进入备份。更换设备或从备份恢复后需使用锁定码或恢复码解锁。
  • Mac 版首次启动时可以导入由早期版本导出的加密迁移包；导入在本机完成，迁移包不包含 API 密钥和目录授权。

8. 系统权限

  • 面容 ID／触控 ID（iPhone，可选）： 仅用于解锁本机加密历史，生物识别数据由系统处理，我们无法获取。
  • 文件访问： 仅访问您通过系统选择器选择的附件和同步文件夹。
  • 网络： 仅用于上文所述的服务商请求（含 Kimi 站点识别）、来源元数据请求和同步文件读写。
  • 后台处理（iPhone）： 用于在您离开应用后继续完成已确认的生成请求，不用于收集数据。
  • 剪贴板： 复制密钥、恢复码或来源链接时使用仅限本机的剪贴板（恢复码复制在两分钟后过期）。

9. 购买与 Apple 提供的信息

本应用通过 App Store 销售，付款由 Apple 处理，我们不会收到您的付款信息。Apple 可能根据您在设备上的设置，向开发者提供汇总的应用分析数据或崩溃报告；这些由 Apple 收集和处理，适用 Apple 的隐私政策。我们可能在 Apple 提供的开发者工具中查看这些汇总数据和崩溃报告，用于定位和修复问题。模型调用费用由您选择的服务商按您与其的约定另行收取。

10. 数据保留与删除

由于数据保存在您的设备和您选择的同步文件夹中，删除由您控制：

  • 聊天与分析： 在“历史管理”中删除单个会话或清空全部本机历史；多模型分析记录在分析历史中删除。删除普通项目只移除分类，聊天保留。
  • API 密钥： 在“接口密钥”中逐个删除；OpenRouter 管理密钥单独删除。删除或更换 Kimi 密钥后，内存中的站点识别结果随之作废。
  • 外发同意记录： 在设置中逐项撤回；撤回即删除该服务商的同意记录。
  • 同步副本： 已共享记录的删除需要完成同步才会传播；同步文件夹中的文件由您在“文件”App 或访达中管理。为防止离线设备恢复已删除内容，同步副本会持续保留删除标记（含项目名称）。
  • 删除应用： 删除应用会移除其应用数据；系统钥匙串条目以及 Mac 上的应用容器是否随之移除取决于系统行为。
  • 服务商已收到的数据： 按该服务商的政策处理，需要时请直接联系该服务商或在其控制台中管理（例如 Kimi 远端文件、Kimi 云端记忆）。Kimi 远端文件的删除请求只发往上传站点；其他站点的文件记录保留，需换回该站点的密钥后删除，或在该站点控制台中处理。

11. 安全

我们采取了上述本机加密、密钥隔离、按上文规则仅在需要时解密密钥、对服务商请求拒绝重定向和回显密钥的响应等措施。 但任何系统都无法保证绝对安全，请保护好您的设备、锁定码、恢复码和 iCloud 账户。

12. 儿童

本应用不面向儿童，我们不会有意收集任何人的个人信息。各服务商可能对使用者年龄有自己的要求，请查阅其条款。

13. 您的权利

我们不持有您的聊天内容、密钥或使用数据，因此通常无法代您访问、更正或删除这些数据；您可以直接在应用中管理，或向相关服务商提出请求。若适用法律赋予您其他权利，您可以通过下方方式联系我们。

14. 政策变更

如本应用的数据处理方式变化（例如新增服务商或功能），我们会更新本政策并修改“最近更新”日期；重大变更会同时在支持页和应用更新说明中提示。
